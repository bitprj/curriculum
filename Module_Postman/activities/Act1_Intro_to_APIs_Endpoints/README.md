# Activity/Lab Name

Intro to API Endpoints

# Long Summary

Students will learn how to use an API along with http methods and interpret status codes. Then they will learn how to interact with an API using Postman. Also students will learn what an API key is and how to use it within Postman. 

# Short Summary

Utlilize postman to interact with an API. 

# Criteria

1. What is an API and why is it useful to developers? 
2. What are the different http methods?
3. What is the purpose of an API key?


# Difficulty

Easy
