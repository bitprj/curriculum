# Activity/Lab Name

Intro to API Endpoints

# Long Summary

Students will learn what an API is and how to use Postman to send a request to the API to get data back. 

# Short Summary

Utlilize postman to get JSON data from API. 

# Criteria

1. What is an API and why is it useful to developers? 
2. What are the different http methods?
3. What is the purpose of an API key?


# Difficulty

Easy
